# login-page 能力规格（增量）

## Purpose

为平台入口提供企业级登录页：左右分栏布局，左侧深蓝渐变品牌区传达产品定位与能力亮点，右侧表单区承载既有登录流程，窄屏自动降级为单栏，视觉与全局科技深蓝主题统一。

## ADDED Requirements

### Requirement: 左右分栏布局

登录页 SHALL 采用左右分栏布局：左侧品牌区占约 55% 宽、深蓝渐变底（#0B1B33 → #123C8C → #2563EB 系）并带光斑装饰；右侧表单区为白底、内容垂直水平居中。视口宽 < 992px 时 SHALL 隐藏品牌区，仅保留居中的表单区。

#### Scenario: 桌面宽度渲染双栏

- **WHEN** 视口宽度 ≥ 992px 打开 /login
- **THEN** 页面呈左右两栏，左栏为深蓝渐变品牌区，右栏为白底登录表单，无横向滚动条

#### Scenario: 窄屏降级单栏

- **WHEN** 视口宽度 < 992px（或移动端）打开 /login
- **THEN** 品牌区不渲染，表单区垂直水平居中显示，可用性不受影响

### Requirement: 品牌区内容

品牌区 SHALL 自上而下展示：产品标识行（Logo 图 + 「Lacus 数据平台」名称）、定位标语「采集 · 计算 · 质量 · 服务化」，以及不少于四条平台能力亮点（多源实时采集 / Flink·Spark 实时与离线计算 / SQL 发布统一 API / 数据质量治理）。文字在深色底上 SHALL 保持 WCAG 可读对比度。

#### Scenario: 品牌信息完整呈现

- **WHEN** 桌面宽度下查看登录页左栏
- **THEN** 能看到产品名、定位标语与四条带勾选图标的能力亮点，文字清晰可读

### Requirement: 表单区构成与功能保持

右栏 SHALL 包含：「欢迎登录」主标题与平台名副标题、账号输入框、密码输入框、验证码输入框+图片（验证码开关开启时）、「记住密码」复选框、登录按钮、可选的注册链接，以及右栏底部版权行。全部既有交互逻辑——表单校验、验证码获取刷新、记住密码 Cookie 存取、登录跳转 redirect、错误后刷新验证码——SHALL 保持现状零行为变更。

#### Scenario: 正常登录流程不受影响

- **WHEN** 用户在改版后的登录页输入正确账号密码（及验证码）并提交
- **THEN** 登录成功并按 redirect 跳转首页，行为与改版前一致

#### Scenario: 登录失败刷新验证码

- **WHEN** 登录请求失败且验证码开关开启
- **THEN** 表单下方出现错误提示路径不变，验证码图片自动刷新

### Requirement: 移除粒子动画依赖

登录页 SHALL 不再引用 three.js 粒子背景组件；`three` 依赖 SHALL 从 package.json 移除，构建产物中不残留该库。

#### Scenario: 构建无 three 引用

- **WHEN** 执行生产构建
- **THEN** 构建成功，产物中不包含 three 库代码，构建体积较改版前下降
