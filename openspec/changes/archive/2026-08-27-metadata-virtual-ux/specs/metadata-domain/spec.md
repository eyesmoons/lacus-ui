## MODIFIED Requirements

### Requirement: 数据源列表与基础操作

系统 SHALL 依据数据源类型收敛行操作按钮：常规（JDBC）源保留「同步元数据」「定时同步」「同步日志」三个同步类按钮；**虚拟源（KAFKA/HDFS）行隐藏这三个同步类按钮**（虚拟源无 JDBC 同步业务语义），仅保留测试连接/编辑/删除入口。虚拟源判定按行数据 `type` ∈ KAFKA/HDFS（与「虚拟源」标签一致）。分页查询、启停、连通性测试、删除、连接参数详情等基础操作不受影响。

> 变更说明（MODIFIED）：原契约对所有数据源行均展示同步元数据/定时同步/同步日志；现对虚拟源收敛，仅虚拟源行隐藏同步三元组。

#### Scenario: 虚拟源行无同步类按钮

- **WHEN** 用户查看数据源列表中某 KAFKA（或 HDFS）虚拟源行的操作按钮
- **THEN** 该行不显示「同步元数据」「定时同步」「同步日志」，仅保留测试连接/编辑/删除

#### Scenario: 常规源行保留同步类按钮

- **WHEN** 用户查看常规（JDBC）数据源行的操作按钮
- **THEN** 三个同步类按钮依旧显示，行为与原契约一致

### Requirement: 数据血缘登记与展示（表维度）

系统 SHALL 允许通过数据源→数据库→表三级联动选择血缘登记/编辑的关联表，而非手动输入表名。登记/编辑弹窗内含三个级联下拉：数据源（datasourceApi.getDatasourceList）→ 数据库（dbApi.getDatasourceList(dsId)）→ 表（tableApi.listTable({datasourceId, dbName})），自动排除当前表与同方向已登记邻居；编辑时按当前血缘行的数据源/库/表三级预填并可改选。其余契约（来源标签、权限控制、登记去重、编辑仅 MANUAL、删除确认）不变。

> 变更说明（MODIFIED）：原契约关联表经「输入表名远程搜索」（listTable({tableName})）选择；现改为三级联动下拉。

#### Scenario: 三级联动选择关联表

- **WHEN** 用户打开登记血缘弹窗,依次选择数据源→数据库→表
- **THEN** 切换数据源加载其库列表、切换库加载其表列表,选中后以该表 ID 作为登记/编辑的 sourceTableId(上游)或 targetTableId(下游)

#### Scenario: 编辑血缘时三级预填

- **WHEN** 用户编辑一条 MANUAL 血缘
- **THEN** 关联表按该行所属数据源/库/表预填三级选择器,用户可改选或仅改依赖类型/备注
