## Purpose

为 OneAPI 接口提供接口文档导出能力，使调用方可获得与发布态一致的 Markdown 文档，覆盖接口元信息、请求参数、响应参数与调用示例，支持单个与批量导出。

## ADDED Requirements

### Requirement: 单个接口文档导出

系统 SHALL 在接口详情页提供「导出文档」入口，点击后请求 GET /one/api/export?apiIds={apiId} 获取该接口的 Markdown 文档并以文件形式下载（文件名 `接口名称.md`）；导出入口仅对已发布（上线）接口可用，未发布接口禁用并提示「接口未上线，无法导出」。文档内容 MUST 至少包含：接口名称、请求方式、接口地址、接口描述、超时时间、限制条数、请求参数表（参数名/类型/是否必填/示例值）、响应参数表（列名/类型）、调用示例。

> 变更说明（ADDED）：详情页此前无导出入口，现新增单个导出。

#### Scenario: 导出已上线接口文档

- **WHEN** 用户在某已上线接口的详情页点击「导出文档」
- **THEN** 浏览器下载名为 `<接口名称>.md` 的文件，其内包含该接口的元信息、请求参数表、响应参数表与调用示例

#### Scenario: 未上线接口禁用导出

- **WHEN** 用户在未上线接口的详情页查看导出按钮
- **THEN** 按钮禁用并提示「接口未上线，无法导出」，不发起导出请求

### Requirement: 批量导出接口文档

系统 SHALL 在接口列表页支持勾选多个接口后点击「批量导出」，请求 GET /one/api/export?apiIds={逗号分隔的apiIds} 获取聚合 Markdown 文档（每个接口一段，按接口名分节）并以单个文件下载；未勾选时按钮禁用；导出请求进行中按钮置 loading 态防止重复点击；导出失败时提示「导出失败，请重试」并保留列表当前选择与查询条件。

> 变更说明（ADDED）：列表页此前无批量导出，现按勾选集合导出。

#### Scenario: 批量导出勾选接口

- **WHEN** 用户在列表页勾选 3 个接口并点击「批量导出」
- **THEN** 发起携带三个 apiIds 的导出请求，成功后下载一份包含三节（每接口一节）的 Markdown 文件

#### Scenario: 未勾选时禁用批量导出

- **WHEN** 列表页无任何勾选
- **THEN** 「批量导出」按钮禁用，不可点击

#### Scenario: 导出失败保留现场

- **WHEN** 批量导出请求返回失败
- **THEN** 提示「导出失败，请重试」，列表勾选与查询条件不丢失，按钮恢复可点击
