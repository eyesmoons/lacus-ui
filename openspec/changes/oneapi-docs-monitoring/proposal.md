## Why

OneAPI 模块目前只能「构建—调试—上下线」，接口一旦上线便处于黑盒状态：调用方没有可下载的接口文档，运维方无法感知调用健康度、成功率和耗时趋势，也无从回溯某次调用。本次变更为 OneAPI 补齐「文档可导出、调用可观测」的运营闭环，使接口从发布到运营全链路可视。

## What Changes

- **接口文档导出**：在 API 列表与详情页新增导出入口，支持单个/批量导出为 Markdown 文档（含接口元信息、请求参数、响应参数、示例）；列表页支持按勾选批量导出。
- **API 监控**：新增监控页面，按接口维度展示调用健康度（近 N 时/天的调用次数、成功数、失败数、错误率、平均/P95 耗时），支持异常阈值标红与按数据源/状态过滤。
- **统计页面**：新增统计概览页，提供调用总量、成功率、Top 调用接口、耗时与错误趋势图表，支持时间区间与数据源维度筛选。
- **调用历史**：新增调用历史列表页，分页展示每次调用的接口、入参摘要、响应状态、耗时、调用方、时间，支持按接口/状态/时间区间检索与详情下钻。

## Capabilities

### New Capabilities

- `oneapi-doc-export`: 接口文档导出——单个/批量导出 OneAPI 接口为 Markdown 文档的契约（导出入口、文档结构、批量选择范围、导出失败处理）。
- `oneapi-observability`: OneAPI 可观测性——基于调用记录的 API 监控看板、统计概览与调用历史列表的契约（指标口径、维度过滤、分页检索、下钻与阈值标红）。

### Modified Capabilities

（无。现有 `oneapi-domain` 的列表/向导/状态机/编辑保护行为不变；导出与监控为新增入口，不改写既有需求。）
